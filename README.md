# Gerenciador Logístico


Aplicação web desenvolvida para a Atividade Prática Orientada (APO) da disciplina de Fundamentos de Programação para Internet da UNIPAR EAD.


O sistema foi feito em PHP, HTML, CSS, JavaScript, Bootstrap e MySQL (rodando localmente com XAMPP) para ajudar no controle básico de logística.


Nele é possível cadastrar, listar, editar e excluir produtos, endereços (origem e destino) e transportadores. A partir desses cadastros, o usuário consegue gerar fretes ligando vários produtos a um único transportador, usando campos dinâmicos em JavaScript, e também baixar um relatório em CSV com os fretes de uma data escolhida.


Tecnologias utilizadas: PHP, HTML, CSS, JavaScript, Bootstrap, MySQL, XAMPP, Git e GitHub.
